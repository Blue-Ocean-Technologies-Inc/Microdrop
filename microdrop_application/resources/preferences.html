Preferences

Edit ▸ Preferences... opens one window with a tab for each part of MicroDrop: the look of the window, the device viewer, the camera, protocols, the image viewer, remote access and your instrument.

Start with the short walkthrough. After that, use the settings finder to look up any setting, its default and when a change takes effect. The cards below it explain the settings people change most.

Overview

What you see in the Preferences window depends on your instrument and on Advanced Mode.

  • Always there: Microdrop General, Device Viewer, Video Settings, Protocol Settings, Image Viewer and SSH / Remote Backend.
  • DropBot (also the mock DropBot): two more tabs, Dropbot Settings and DropBot Status & Controls, and a Protocol Setters Config box at the bottom of Protocol Settings.
  • Portable DropBot: one more tab, Portable DropBot Settings.
  • OpenDrop: no extra tab.
  • Advanced Mode (Edit ▸ Advanced Mode): adds the Advanced Mode tab at the end.
  • Plugins installed with Tools ▸ Manage Plugins… (the heater, the magnet, fluorescence and others) can add tabs of their own. Their own tutorials describe them.

Each tab is made of boxes, one per group of settings. Most settings are saved in preferences.ini in MicroDrop's settings folder. The Help, Logs & Saved Files tutorial (Help ▸ Tutorials) explains where that file is and when MicroDrop writes it.

Tab map Interactive

Pick your instrument, switch Advanced Mode on or off, then click a tab to see its boxes and which tutorial covers it.

Quick walkthrough

Five short tasks: open the window, change a setting, keep or undo it, and find the extra tab.

  1. 1Open Preferences

    Choose Edit ▸ Preferences.... The Preferences window opens with its tabs along the top and four buttons along the bottom: Apply, Revert, OK and Cancel. While it is open, the main window waits.

  2. 2Tour the tabs

    Click each tab. Every box has a title, such as Canvas Background on Microdrop General or Main View on Device Viewer. Some boxes appear only after a choice: the FFmpeg Recording box on Video Settings shows only when the recording engine is FFmpeg.

  3. 3Change one setting and press Apply

    On Microdrop General, set Color Scheme under Appearance to Dark, then click Apply. The whole of MicroDrop turns dark at once. Apply saves the tab you are on; OK saves every tab and closes. Many settings work at once like this one; others wait for the next run or the next start (the finder says which).

  4. 4Undo it

    Before you apply, Cancel throws your changes away. After you apply, set the value back by hand. Revert is not an undo: it puts every setting the tab stores back to its default, at once (see Revert).

  5. 5See the Advanced Mode tab

    Close the window, tick Edit ▸ Advanced Mode and open Preferences again. A tab named Advanced Mode is now last. Untick Advanced Mode when you are done: it also changes what you can edit during a run (see Advanced Mode).

Shortcut to the sidebar sizes. Right-click the Device Viewer's sidebar and choose Modify Layout.... A small window opens with the four Sidebar View sizes. Changes made there apply straight away; you do not need the Preferences window.

The four buttons

The window has no toolbar. Everything happens through the four buttons, and they do not all act on the same tabs.

Apply Bottom of the window

Saves the changes on the tab you are looking at. The window stays open.

What it is

Only the current tab. Changes you made on other tabs stay on screen, not yet saved, until you apply them there or press OK.

When to use it

To try a setting while you watch its effect, for example the colour scheme or the canvas background.

OK Bottom of the window

Saves the changes on every tab and closes the window.

What it is

Every tab you can see, including the ones you changed but did not apply. With Advanced Mode off, the hidden Advanced Mode tab is left alone.

When to use it

The normal way to finish.

Cancel Bottom of the window

Closes the window and throws away the changes you did not apply.

How to read it

Anything already saved with Apply or Revert stays saved. Cancel does not undo it.

Revert Bottom of the window

Puts every setting of the current tab back to its default, and saves that at once.

What it is

There is no "Restore Defaults" button; Revert is it. It acts on the current tab only, but on everything that tab stores, including values the tab does not show. It does not ask first, and Cancel does not bring the old values back.

How to read it
TabAlso reset by Revert, though not shown on the tab

Device ViewerThe default device (back to the bundled 90_pin_array.svg), your zone types, the layer opacity and visibility table, the camera-alignment marker style, the Recording Viewer's zoom and overlays, and Auto-commit
Video SettingsThe remembered camera and resolution

Try the buttons Interactive

A two-tab Preferences window. Change a value, switch tabs, and watch the In use line: it is what MicroDrop actually works with.

Settings finder

Every setting in the Preferences window, with its box, its default and when a change takes effect. Type to search, or pick a tab.

  • Apply: works as soon as you press Apply or OK.
  • Next run / Next recording / Next start: saved at once, used the next time that happens.
  • Defaults are those of a fresh install. Rows marked DropBot, Portable or Advanced Mode appear only there.

All settings All tabs

The labels are the ones in the window, word for word.

Microdrop General

How the main window looks and starts, one notice you can silence, and how much MicroDrop logs.

Color Scheme Microdrop General ▸ Appearance ▸ Color Scheme

Light or dark windows for all of MicroDrop.

What it is

Three choices: Follow system uses your computer's light or dark setting; Light and Dark force one.

When to use it

Force one when the computer's choice makes MicroDrop hard to read, for example a dark room at the bench.

How to read it

Changes as soon as you press Apply.

Typical value

Follow system.

Dock Separator Color Microdrop General ▸ Appearance

The colour of the thin bars between the docked panes.

What it is

Follow system, Light and Dark pick that scheme's grey; Custom uses Custom Separator Color (hex), which can only be edited when Custom is chosen.

When to use it

When the bars are hard to see and grab.

Typical value

Follow system; custom colour #d1d1d1.

Always Use Default Layout Microdrop General ▸ Application Startup

Open with the standard pane arrangement every time, instead of the one you left.

What it is

Normally MicroDrop restores where each pane was when you last closed it. Ticked, it ignores that and starts with the default layout.

When to use it

On a shared instrument, so every user starts from the same window.

How to read it

Takes effect at the next start. If MicroDrop cannot restore your saved layout, it ticks this box for you; untick it to get your own layout back.

Typical value

Off.

Use Custom Color Microdrop General ▸ Canvas Background

Paint the empty area in the middle of the main window with your own colour.

What it is

Off, the area is white in light mode and black in dark mode. On, it uses Background Color (hex).

When to use it

To make the bench screen easier on the eyes, or to tell two instruments apart at a glance.

Typical value

Off.

Background Color (hex) Microdrop General ▸ Canvas Background

The custom canvas colour, as a hex code such as #ffffff.

What it is

Click the field to pick a colour. It can be edited only while Use Custom Color is ticked.

Typical value

#ffffff (white).

Opacity (%) Microdrop General ▸ Canvas Background

How solid the canvas colour is, 0 to 100 %.

What it is

Applies to whichever colour is in use, custom or automatic. 100 % is fully solid; lower values let what is behind the canvas show through.

How to read it

A slider. Changes as soon as you press Apply.

Typical value

100.

Suppress no shorts information Microdrop General ▸ Dialog Settings

Stop the No Shorts Detected message after an automatic short check.

What it is

When a short check finds nothing, MicroDrop says No shorts were detected. with a Do not show again (can be undone from preferences) box. Ticking that box ticks this setting. Untick it here to see the message again. A check you start yourself always shows its result.

Typical value

Off.

Experiments folder Not in the window

Where MicroDrop makes a folder for each experiment.

What it is

There is no field for it on this tab. MicroDrop uses <home>\Documents\Sci-Bots\Microdrop\Experiments and creates it if needed. Revert on Microdrop General sets it back to that folder.

How to read it

The Help, Logs & Saved Files tutorial describes what each experiment folder holds.

Typical value

Documents\Sci-Bots\Microdrop\Experiments.

Log level Microdrop General ▸ Logger Settings ▸ Level

How much MicroDrop writes to its log, from Debug (everything) to Critical (least).

What it is

The only setting in the Logger Settings box. The Help, Logs & Saved Files tutorial explains the levels and the log file.

How to read it

Takes effect when you press Apply or OK.

Typical value

Info.

Log pane buffer and filters The Microdrop Console Logs pane

Not in this window: set them in the log pane itself.

What it is

The pane's Buffer (how many lines it keeps, 10 to 100 000) and its Debug, Info, Warning and Error filters are remembered between sessions, but you change them in the pane.

Typical value

Buffer 10; Debug off; Info, Warning and Error on.

Device Viewer

The device drawing, its zoom, the sidebar, slugs and the volume readout. The Device Viewer and Zones tutorials cover the pane itself.

Default Device Layout Device Viewer ▸ Main View

The device (.svg) file MicroDrop opens at start.

What it is

A file box with a browse button. MicroDrop also updates it each time you open a device, so it normally holds the last device you used.

When to use it

Point it at the chip you use most if you switch devices often.

How to read it

Used at the next start. If the file is missing, MicroDrop goes back to its bundled 90_pin_array.svg.

Typical value

Documents\Sci-Bots\Microdrop\Devices\90_pin_array.svg.

Auto Fit Margin Scale Device Viewer ▸ Main View

How much of the view the device fills when MicroDrop fits it to the pane, in per cent.

What it is

95 leaves a thin margin round the device; 100 fills the view edge to edge.

Typical value

95 (1 to 100).

Zoom Sensitivity Device Viewer ▸ Main View

How big each zoom step is.

What it is

Each zoom in or out scales the view by 1 + value/100: the default 5 zooms by 5 % per step.

When to use it

Raise it if zooming feels slow; lower it for finer control.

Typical value

5 (1 to 100).

Number of channels Device Viewer ▸ Main View

How many electrode channels your instrument has.

What it is

When you type a channel number while editing a device, MicroDrop accepts 0 up to this number minus one, and refuses the rest.

When to use it

Change it only if your instrument has more or fewer channels than 120.

Typical value

120 (1 to 1024).

Sidebar View sizes Device Viewer ▸ Sidebar View; also right-click the sidebar ▸ Modify Layout...

The width of the Device Viewer's sidebar and the smallest height of three of its sections, in pixels.

What it is

Device Viewer Sidebar Width, and the minimum heights of the opacity table (Alpha View Min Height), the layers list (Layers View Min Height) and the zones list (Zones View Min Height).

When to use it

When a section is too cramped to use, or the sidebar takes too much room on a small screen.

How to read it

Changes as soon as you apply. The Modify Layout... window edits the same four values.

Typical value

Width 320; heights 180, 250 and 250 (each 0 to 10000).

Max slug width (electrodes) Device Viewer ▸ Paths

The widest slug the route sidebar lets you draw, counting the route electrode itself.

What it is

The route sidebar's two lane sliders together can add at most one less than this.

Typical value

5 (1 to 21).

Plate gap (µm) Device Viewer ▸ Volume Readout

The distance between the top and bottom plates the droplet fills.

What it is

The live volume readout is the liquid-covered area times this gap, so a wrong gap makes every volume wrong by the same factor.

When to use it

Set it to your chip's spacer height.

Typical value

254 µm (1 to 2000).

Video Settings

Which camera formats are offered, and how recordings are encoded. The Camera & Alignment tutorial covers the camera pane.

Preferred Video Format Video Settings ▸ Video Format

The camera picture format MicroDrop offers first: NV12 or JPEG.

What it is

With Strictly Use Only Preferred Video Format? ticked, the camera's resolution list shows only resolutions in this format. Unticked, other formats are offered too, the preferred one first.

When to use it

Untick Strictly if your camera's resolution list is empty or missing the size you need.

How to read it

The camera pane's resolution list refreshes as soon as you apply.

Typical value

NV12 on Windows and macOS, JPEG on Linux and the Pi; Strictly on.

Hide High Resolution Warning Video Settings ▸ Video Format

Skip the notice shown when you pick a camera resolution above Full HD (1920x1080).

Typical value

Off.

Recording Engine Video Settings ▸ Video Recording

What turns camera frames into a video file.

What it is

Qt MediaRecorder (hardware) uses your computer's own video encoder, with the least work for the processor. FFmpeg process sends the frames to a separate ffmpeg program: more choice, more processor load. The box below changes to match.

How to read it

Every recording is set up from these settings when it starts, so a change applies from the next recording.

Typical value

Qt MediaRecorder (hardware).

Qt recording: format, codec and quality Video Settings ▸ Qt Recording

The file type and how much detail each second of video keeps.

What it is

Video Format: MP4 plays everywhere, but a crash while recording can leave the file unreadable; MKV stays readable after a crash. Video Codec lists only what this computer can encode. With MKV, the MKV Quality box sets a quality tier for each of four resolution classes (1080p or 4K, at 30 or 60 fps): pick the class under Resolution, then its tier. Each tier shows its bitrate and about how many MB one minute takes.

How to read it

When a recording starts, MicroDrop uses the tier of the class nearest the camera's real resolution and frame rate.

Typical value

MP4 with H264; every tier Auto (for 1080p at 30 fps, 4.5 Mbps).

FFmpeg recording settings Video Settings ▸ FFmpeg Recording

Shown only when the engine is FFmpeg process.

What it is

Container mkv or mp4 (mkv survives a crash). Video Codec libx264 (fast, plays everywhere) or libx265 (about half the size, more processor). Preset trades speed for file size. Quality (CRF): 0 is lossless, 51 the worst; about 17 looks lossless. Extra Output Args adds ffmpeg options; leave it empty unless you know ffmpeg.

How to read it

Frame rate, resolution and pixel format always come from the camera.

Typical value

mkv, libx264, ultrafast, CRF 17, no extra arguments.

Protocol Settings

Waits around a run, two questions MicroDrop can stop asking, how long a run waits for each column, and, with a DropBot, the voltage and frequency ranges. The Protocol Tree tutorial covers running protocols.

Realtime Mode Pre-Protocol (s) Protocol Settings ▸ Protocol Settling Times

How long a run waits for the hardware to settle after turning realtime mode on, before the first step.

What it is

Part of the single wait, shown as a loading screen, before the first step. Preview runs skip it.

Typical value

1.0 s (0.5 to 15).

Logs Accepted Post-Protocol (s) Protocol Settings ▸ Protocol Settling Times

How long after a run ends MicroDrop still accepts readings into that run's log.

When to use it

Raise it if the last readings of a run are missing from its data.

Typical value

3.0 s (0.5 to 15).

Prompt to keep Realtime Mode? and Keep Realtime Mode active? Protocol Settings ▸ Realtime Mode Persistence

What happens to realtime mode when a run ends, if it was already on when the run started.

What it is

If realtime mode is off at the start, the run turns it on and off again at the end. If it is already on: with Prompt to keep Realtime Mode? ticked, MicroDrop asks whether to keep it; with it unticked, it follows Keep Realtime Mode active?. Ticking Don't ask again in that question unticks the prompt and saves your answer here.

Typical value

Both on.

Suppress unused column hooks information Protocol Settings ▸ Dialog Settings

Hide the Protocol Columns Not Used notice, which lists columns whose start and end actions a run skipped because no step uses them.

What it is

The notice's Do not show again box ticks this setting; untick it here to see the notice again.

Typical value

Off.

Column Ack Wait Times Protocol Settings ▸ Column Ack Wait Times (0 = don't wait)

How long a step waits for each column's hardware to confirm it has done its job.

What it is

One row per column that waits, with its Wait Time (s). 0 means do not wait; ∞ (wait forever) waits as long as it takes. The list follows the columns loaded now, so plugin columns appear when their plugin is on.

When to use it

Raise a time when a slow device makes runs stop with a time-out; lower it to find a stuck device sooner.

How to read it
Column (as listed)Default (s)
Electrodes / Routes, Voltage (V), Frequency (Hz)5
Check Droplets, Zone Target12
Capture (camera)15
Set Magnet (Portable DropBot)40
Fluorescence Capture, PMT Capture (Portable DropBot)60
Set Temp (Portable DropBot)120

Plugin columns bring their own defaults. Revert puts every row back to its column's default.

Protocol Setters Config: voltage and frequency ranges Protocol Settings ▸ Protocol Setters Config (DropBot)

The lowest and highest voltage and frequency the spin boxes let you type, and the values they start with.

What it is

These are screen limits: they bound the voltage and frequency boxes in the DropBot status pane and in the protocol. They do not change what the DropBot accepts; its own limits, shown under Hardware Config, still apply. Default Voltage (V) and Default Frequency (Hz) are what the DropBot status pane starts with; they must lie between the min and max.

How to read it

New min and max apply to open boxes at once. The defaults are read at the next start.

Typical value

30 to 140 V, 100 to 10000 Hz; defaults 100 V and 10000 Hz.

Dropbot Settings and DropBot Status & Controls

Two tabs that appear with a DropBot (or the mock DropBot). The Dropbot Status & Controls tutorial covers the status pane.

Capacitance Update Interval (ms) Dropbot Settings

How often the DropBot reports capacitance.

What it is

Lower numbers mean more readings per second and more traffic.

How to read it

Sent to the DropBot when you press Apply or OK. Change it while the DropBot is connected.

Typical value

100 ms.

Drop Detect Capacitance (pF) Dropbot Settings

The capacitance above which an electrode counts as holding a droplet.

When to use it

Raise it if dry electrodes are reported as wet; lower it if small droplets are missed.

How to read it

Sent to the DropBot when you press Apply or OK, and used by the next droplet check. Change it while the DropBot is connected.

Typical value

10 pF.

Hardware Config Dropbot Settings ▸ Hardware Config

Four read-only values from the instrument.

What it is

Max Voltage (V) and Max Frequency (Hz) are the limits the connected DropBot reports; they read inf until a DropBot has connected. Last Applied Voltage (V) and Last Applied Frequency (Hz) are the values last sent to it, kept between sessions.

Typical value

Last applied 100 V and 10000 Hz until you change them.

Default Dielectric Material and Show Dielectric Info DropBot Status & Controls tab

The dielectric the status pane assumes at start, and whether its dielectric readout is shown.

What it is

The material is used to work out the dielectric thickness from the measured capacitance. Picking a material in the status pane also changes this setting, so it normally holds your last choice. Right-clicking the status pane offers the same Show Dielectric Info switch.

How to read it

The material is read at the next start; Show Dielectric Info applies at once.

Typical value

Pick a dielectric... (none); Show Dielectric Info on.

Image Viewer

Deleting experiments, and AI-assisted region detection. The Image Analysis tutorial covers the viewer.

Ask for confirmation before deleting an experiment folder Image Viewer ▸ Experiments

Ask before the image viewer's delete button removes an experiment folder.

What it is

The warning's "don't ask again" box unticks this. Tick it here to be asked again.

Typical value

On.

AI ROI detection model Image Viewer ▸ AI ROI Detection

Which AI model finds regions of interest for you, from fast to accurate.

What it is

EfficientSam, Sam and Sam2, each in speed, balanced or accuracy versions. A model not yet on this computer is downloaded when you apply; cancel the download and the previous model stays.

Typical value

EfficientSam (accuracy).

Run the SAM encoder on the GPU (DirectML) Image Viewer ▸ AI ROI Detection

Use the graphics card for AI detection when it can.

What it is

About three times faster on Windows with the GPU build installed (Help ▸ Install AI ROI Support). Without it MicroDrop says so and keeps using the processor.

Typical value

On.

SSH / Remote Backend

Connection details for an instrument on the network.

Remote Backend fields SSH / Remote Backend ▸ Remote Backend

Host, SSH Port, Username, SSH Key Name, Remote Experiments Path and Device ID.

What it is

The same values the Tools ▸ Remote Controls dialogs (SSH Key Portal, Sync Remote Experiments) use; typing in those dialogs changes them here too. The password is never saved. Device ID follows the host (dots become _) until you give it a name of your own.

How to read it

The dialogs read them each time they open.

Typical value

Host, port and user from MicroDrop's .env file if it has them (port 22 otherwise); key id_rsa_microdrop; path ~/Documents/Sci-Bots/Microdrop/Experiments/.

Portable DropBot Settings

Only with the Portable DropBot. Changes reach the instrument when you apply, except the magnet position, which needs its own buttons.

Fan toggle controls Portable DropBot Settings

Which fan the status pane's fan switch turns on and off.

What it is

MCU board fan or Motor board fans.

Typical value

MCU board fan.

Chip detected when Portable DropBot Settings

How many pogo contacts must touch the chip before MicroDrop says a chip is in.

What it is

Both pogo pads touching the chip or At least one pogo pad touching the chip.

When to use it

Use "at least one" if a seated chip keeps showing as absent.

Typical value

Both pogo pads.

Droplet detection threshold (pF) Portable DropBot Settings

The capacitance an electrode must read to count as holding liquid.

What it is

A starting value. For each channel, thresholds saved in the vendor app and a fresh chip baseline take its place, and the active chip's electrode sizes scale it.

Typical value

5.0 pF (0.1 to 1000).

Engage position (mm) Portable DropBot Settings ▸ Magnet

The height the magnet moves to when engaged.

What it is

Read fills the field from the board (apply to keep it). Write sends the value on screen to the board's memory until it reboots. Preset to flash asks first, then makes the last written value survive reboots. The line below the buttons reports each step.

How to read it

Apply only remembers the number in MicroDrop; it does not send it to the board. Keep it below the magnet's upper travel limit.

Typical value

14.000 mm.

Gain, temperature and move presets Portable DropBot Settings ▸ Presets

The quick-pick buttons beside the PMT gain, heater target and motor move fields.

What it is

Comma-separated numbers, one button each, up to 8. Gains 0 to 255; temperatures −50 to 150 °C; moves −1000 to 1000 mm (negative moves back). Values that do not read as numbers are skipped.

Typical value

Gains 64, 128, 192, 255; temperatures 25, 37, 55, 95; moves −10, −1, −0.1, 0.1, 1, 10.

Display Scale Tools ▸ Display Scale... (Portable DropBot)

Not in Preferences: the size of everything on the instrument's screen.

What it is

A slider from 50 to 200 % of the screen's normal scale. Below 100 % everything shrinks and more panes fit. Apply uses it now, Reset to 100% goes back. MicroDrop applies it again at every start.

Typical value

100 %.

Advanced Mode

A switch in the Edit menu, and the tab it reveals.

Advanced Mode Edit ▸ Advanced Mode

A tick in the Edit menu that unlocks settings and controls meant for experienced users.

What it is

While it is on: Preferences shows the Advanced Mode tab; during a run you can still edit values in the protocol tree (adding, deleting and pasting steps stay locked); on the Portable DropBot, the advanced controls and the port picker appear. Turning it on writes Microdrop Running in Advanced Mode! to the log; turning it off writes Microdrop Advanced Mode is Off.

When to use it

Only when you need one of those. Keep it off for routine work.

How to read it

It is not saved in preferences.ini: it lives in the message server's memory, like the other live values described in the Help, Logs & Saved Files tutorial. Check the tick after a restart.

Typical value

Off.

Allow hardware disables Advanced Mode ▸ Device Viewer

Show channels the hardware has switched off as greyed out and not clickable.

What it is

The hardware disables channels for safety, for example after a short. Ticked, the device viewer shows this. Unticked, every channel looks active whatever the hardware reports.

When to use it

Leave it on. Turning it off hides safety feedback.

Typical value

On.

Caveats

  • Apply saves one tab. Changes on the other tabs wait for their own Apply or for OK. Cancel throws them away.
  • Revert is a reset, not an undo. It resets everything the tab stores, including hidden values such as zone types or AutoSave, saves at once and does not ask. Cancel does not bring the old values back.
  • Some changes wait. Always Use Default Layout, Default Device Layout, the default voltage and frequency and the default dielectric are read at the next start; run settings at the next run.
  • DropBot settings need the DropBot. Capacitance Update Interval and Drop Detect Capacitance are sent to the instrument; change them while it is connected.
  • Screen limits are not hardware limits. Protocol Setters Config bounds what you can type; the DropBot's own limits still apply.
  • Advanced Mode can change what is safe. Its tab can hide hardware safety feedback, and it lets you edit a running protocol. Keep it off for routine work.
  • Settings are saved when MicroDrop closes normally. Do not edit preferences.ini while MicroDrop runs (see the Help, Logs & Saved Files tutorial).
  • Tabs follow your set-up. A tab you remember from another instrument or plugin may simply not be loaded here.

Glossary

Preference
A setting MicroDrop remembers between sessions.
Tab
One page of the Preferences window, usually one part of MicroDrop.
Box
A titled group of settings on a tab.
Default
The value a setting has on a fresh install, and after Revert.
preferences.ini
The text file in MicroDrop's settings folder that holds your settings.
Advanced Mode
A switch in the Edit menu for settings and controls meant for experienced users.
Realtime mode
The state in which electrode changes go to the hardware straight away.
Ack
Short for acknowledgement: the hardware's reply that it has done what a step asked.
Codec
The method used to compress video into a file.
Slug
A droplet wider than one electrode, moved as one along a route.
Plugin
An add-on that gives MicroDrop new panes, columns, tabs or hardware support.
