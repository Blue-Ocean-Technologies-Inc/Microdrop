Zones

Zones put names on parts of a chip: reservoirs, waste, heater spots, parking slots. You make a zone type (a name and a colour), then draw regions of that type over the electrodes. A protocol step can then say "switch on the first parking slot that is still free", without naming electrodes.

This tutorial covers the Zones section of the Device Viewer side panel and the Zone Target protocol column. The clips play when they scroll into view. The two interactive figures let you try drawing regions and the Zone Target rule without a chip.

Overview

Two things to keep apart: a zone type is a label, a region is a patch of electrodes wearing that label. One zone type can have many regions.

  • Zone types are shared by every device. MicroDrop keeps them in its preferences. A fresh install starts with two, heating (yellow) and mixing (red).
  • Regions belong to one device. They are saved inside the device's SVG file, in a layer called Zones, when you save the device.
  • The Zone Target column in the protocol tree lets a step switch on one region of a zone type, chosen at run time by whether a droplet sits on it.

The Zones section sits in the side panel to the right of the Device Viewer, below Alpha Settings and Paths. If the panel is hidden, click the strip at the picture's right edge, then click the Zones heading to fold it open.

Two different numbers for one region. The Zones table numbers the regions of a zone type by their place in the list: 1, 2, 3. Each region also has a fixed id such as zone-1-4, which is never handed out again, even after the region is deleted. The Zone Target tooltip, the run log and the run report use the id. Hover a region's row in the Zones table to see its id.

Quick walkthrough

From an empty zone list to a protocol step that picks a region on its own. Steps 1 to 3 were recorded on one chip, steps 5 and 6 on the same chip a little later; the worked example after this list uses a different chip layout.

  1. 1Add a zone type

    Click Add zone type. A new row appears in the table under the buttons, named zone- plus its row number, with the next colour in MicroDrop's list.

    To rename it, double-click the name and type. To change its colour, click the colour swatch: the Select Color window opens.

    New regions go to the zone type whose row is selected, so click the row of the type you want to draw.

  2. 2Draw regions and commit each one

    Click Draw zones (it turns blue while on). Drag a box over the electrodes you want: every electrode the box touches joins a dashed selection. Click a single electrode to add or remove just that one.

    Click Commit zone. The selection becomes a region: it fills with the zone colour, and a numbered row appears under the zone type, whose # count goes up by one. Repeat for each region.

  3. 3Select, hide and show regions

    Click Select zones. Now a click on a region selects it: its outline gets thicker and its row in the table is highlighted. Ctrl+click adds more regions to the selection.

    Each row has an eye . Click it to hide that region (the eye is crossed out) and again to show it. The eye on a zone type's own row hides or shows all of its regions.

  4. 4Save the device

    Choose File ▸ Device ▸ Save (or Save As…). MicroDrop writes every region into the device SVG file's Zones layer, with its zone type's name and colour.

    Do this before you load another device or close MicroDrop. Zone edits do not mark the device as changed, so MicroDrop will not remind you, and unsaved regions are gone the next time the file is loaded.

  5. 5Pick a zone type for a step

    The Zone Target columns are hidden at first. Right-click the protocol tree's column headings and tick Zone Target and Zone Criterion.

    Double-click a step's Zone Target cell and pick a zone type; (none) switches the feature off for that step. The Zone Criterion cell next to it fills with Has Droplet; double-click it to change it to No Droplet.

    Hover the Zone Target cell: the tooltip lists the regions in the order they will be checked, by id.

  6. 6Run the step

    Run the protocol, or right-click a step and choose Run Selected Steps. At the start of the step MicroDrop asks the DropBot which electrodes of the zone type's regions have liquid on them, takes the first region in check order that meets the criterion, and switches it on together with the step's own electrodes and routes, for the whole step.

    If no region qualifies, the step fails with a Protocol error message (see When the step fails).

Worked example: send the droplet to the first free slot

A recording on a different layout. There is one zone type, zone-1, with two regions: a 2×2 patch near the top with a green droplet on it, and a row of four electrodes at the bottom that is empty. The protocol has three steps:

StepElectrodesRoutesZone TargetZone CriterionWhat happens
120Holds the red droplet where it is.
201The route carries the red droplet down, to just above the bottom row.
300zone-1No DropletThe top patch has a droplet, so it is skipped. The bottom row has none, so it is switched on, and the red droplet moves onto it.

Step 3 names no electrodes at all; the zone decides. If you add more parking regions to zone-1, the same step fills them one by one in the order you drew them, until none is free and the step fails.

Zone terms

What the words in the Zones section mean, and what MicroDrop starts with.

Zone type Zones table, top-level rows

A label with a name and a colour, such as waste in blue.

What it is

The kind of place a region is. Each zone type has a fixed id (its first name, or that name with -2, -3 … if it was taken) and a name you can change. Renaming keeps the id, so protocol steps that use the zone type keep working.

When to use it

Make one per kind of place you want to talk about: reservoirs, waste, parking slots, detection spots.

How to read it

The # column counts its regions on the loaded device.

Typical value

heating (yellow) and mixing (red) on a fresh install. New ones are called zone-row number and take the next colour of: yellow, red, green, blue, pink, orange.

Region Zones table, numbered rows; coloured patches on the device

A set of electrodes that belongs to one zone type.

What it is

The list of electrodes is what MicroDrop stores; the coloured patch and its outline are drawn from it. Because the region knows its electrodes, it also knows their channels, which is what the Zone Target column switches on.

When to use it

One region per place: three parking slots of the same kind are three regions of one zone type.

How to read it

A filled patch in the zone type's colour with a solid outline. Where regions of two zone types overlap, the colours blend; the layer order decides which is drawn on top.

Typical value

None until you draw some. Regions are per device.

Region number and region id region row tooltip, Zone Target tooltip, run report

The table shows a region's place in its list; the id is its permanent name.

What it is

The id is the zone type's id, a dash, and a counter: zone-1-4. The counter only ever goes up for that zone type, even across undo and after deletions, so an id is never reused. The row number is just the region's position, so it changes when an earlier region is deleted.

When to use it

Use the id whenever you compare what the table shows with the Zone Target tooltip, the log or the run report: those always use ids.

How to read it

Hover the region's row in the Zones table to see its id. Moving a region to another zone type with Change type gives it a new id in that type.

Typical value

heating-1, heating-2 … for a fresh zone type.

Outline device view

The line drawn around a region, computed from its electrodes; you never draw it yourself.

What it is

MicroDrop joins the shapes of the region's electrodes. To make neighbours read as one patch it closes the gaps between them, up to a little more than the narrowest gap between any two electrodes on the device (1.2 times it), while a skipped electrode still shows as a hole.

How to read it

A selected region's outline is drawn thicker. Where neighbouring electrodes sit further apart than that, the gaps stay open and the outline traces each electrode. That is what you see in the clips above, recorded on the 90-pin array: most of its neighbouring electrodes are twice as far apart as its narrowest gap, so each region still shows its electrode lines.

Typical value

2 px; 4 px when selected.

Layer order Zones table order; up/down arrows

Which zone type is drawn on top where regions overlap.

What it is

The first zone type in the table is the top layer, the last is the bottom one. Use and on the selected zone type to move it.

When to use it

When regions of different types share electrodes, for example a detection spot inside a reservoir.

How to read it

Only the drawing order changes. It does not change the order in which the Zone Target column checks regions.

Typical value

The order you added the zone types in.

Draw mode Draw zones button

The tool for building a dashed selection of electrodes that will become a region.

What it is

Each box you drag adds every electrode it touches, even a corner. A plain click adds or removes one electrode, for shapes a box cannot make. The selection is drawn dashed in the colour of the zone type it will become.

When to use it

To make new regions, and while editing one (Edit region switches to draw mode by itself).

How to read it

The button is blue while on. The status bar shows the Device Viewer's current mode.

Typical value

Off. Choosing another Device Viewer tool turns it off.

Undraw second button of row 1; Ctrl+drag

Makes your boxes take electrodes out of the dashed selection instead of adding them.

What it is

The switch for screens without a keyboard; holding Ctrl while you drag does the same.

When to use it

To carve a notch out of a large box, or to trim a region during Edit region.

How to read it

While you drag, the rest of the selection shows red and the electrodes the box touches drop out of it.

Typical value

Off. Usable only in draw mode.

Select mode Select zones button

The tool for picking regions that already exist.

What it is

A click selects the region under the pointer; the selected one gets a thicker outline and its row is highlighted. Selected regions can be edited, merged, deleted, hidden or moved.

When to use it

Everything that changes or removes a finished region.

Typical value

Off.

Multi-select fourth button of row 1; Ctrl+click

Makes a click add a region to the selection, or take it out, instead of replacing it.

What it is

The touch-screen version of Ctrl+click. It works on the canvas and in the table.

When to use it

To select several regions, usually to merge them or move them together.

Typical value

Off. Usable only in select mode.

Commit Commit zone button

Turns the dashed selection into region(s) of the zone type selected in the table.

What it is

If the selection is in separate pieces, each piece that does not touch the others becomes its own region, biggest first. Touching is judged by the device's own neighbour connections.

When to use it

After every selection you want to keep. Nothing is a region until it is committed.

How to read it

The dashed selection becomes a filled patch, a numbered row appears, and the zone type's # goes up.

Typical value

Greyed out until something is selected in draw mode.

Merge Merge button, row 2

Joins several selected regions into one.

What it is

Allowed when two or more regions are selected, all of one zone type, and together they form one connected block. The merged region keeps the id and the list place of whichever of them was made first.

When to use it

When you drew one place in several pieces.

How to read it

The button is greyed out while the selection does not qualify, for example when the regions do not touch or belong to different zone types.

Typical value

Off until a qualifying selection exists.

Edit region Edit region button, canvas strip, right-click menu

Reopens a region's electrodes as a dashed selection so you can add or remove some.

What it is

MicroDrop switches to draw mode and hides the committed patch while you work. Commit zone updates the same region, keeping its id. If your changes cut it into pieces, the biggest piece stays this region and the others become new regions of the same type. Committing an empty selection leaves the region as it was.

When to use it

To grow, shrink or reshape a region without losing its id.

How to read it

Clear selection or Esc cancels: the region comes back unchanged. Either way you land back in select mode.

Moving a region select mode, drag a region

Drag a region in select mode to shift it across the electrode grid.

What it is

Each electrode of the region moves to the electrode nearest its new spot. With several regions selected, dragging one of them moves them all.

How to read it

If a region would leave the device or break apart, nothing moves and the status bar says Move rejected: regions must stay on the device and contiguous for a few seconds.

Zones layer in the device SVG the device's .svg file

Where regions are saved: a layer named Zones inside the device file.

What it is

One entry per region, holding its id, its zone type's id, name and colour, whether it is shown, and its electrode ids. MicroDrop rewrites the layer each time the device is saved and reads it when the device is loaded.

When to use it

Every File ▸ Device ▸ Save or Save As….

How to read it

When a saved region names electrodes the file no longer has, MicroDrop trims or drops it and shows Zones Not Loaded: N zone region(s) in this device file reference electrodes that do not exist in it and were dropped or trimmed. Saving the file will write it without those electrodes.

Typical value

No layer until the first save with regions.

Zones snapshot (for other plugins) shared app data, key microdrop.device.zones

A live copy of every zone type and its regions that other parts of MicroDrop read.

What it is

MicroDrop republishes it after every change, saved or not: for each zone type its name, colour and regions, each region with its id, electrode ids and channels, in check order. The Zone Target column reads it.

When to use it

Nothing to do: it follows the Zones section on its own.

How to read it

Developers: the key is ZONES_KEY in device_viewer/consts.py.

Typical value

Reflects the loaded device.

Zones transparency Alpha Settings ▸ Zones

The Zones row of Alpha Settings sets how strongly all regions are drawn.

What it is

At 100 the zone fill is 43 % opaque, so the electrodes and the camera picture show through. Lower values fade the regions; 0, or the row's eye switched off, hides all of them.

When to use it

When regions hide what is under them on the camera picture.

Typical value

100, shown.

The Zone Target column

Two cells per step in the protocol tree, added by the zone protocol controls plugin. They let a step switch on "the first region of this type that has (or has no) droplet" without naming electrodes.

Zone Target protocol tree ▸ Zone Target

The zone type whose regions the step chooses from.

What it is

A drop-down of (none) and every zone type by name; the cell then shows the zone type's id. A zone type deleted since stays in the list as id (missing), so the step does not lose it silently.

When to use it

On steps that should act on "a free slot" or "the slot that holds liquid". Leave it at (none) everywhere else: then the column does nothing and asks the DropBot nothing.

How to read it

Hover the cell. With a zone type picked: Regions, checked in this order: … (ids). With none: Pick a zone type: at step start, the first of its regions meeting the Zone Criterion is actuated with the step. For a deleted type: Zone type '…' is not defined on the loaded device; this step fails when run.

Typical value

(none). The column is hidden until you tick it in the header's right-click menu.

Zone Criterion protocol tree ▸ Zone Criterion

Which region counts as a match: one with a droplet, or one without.

What it is

Has Droplet: a region counts if the DropBot detects liquid on any of its electrodes. No Droplet: a region counts if it detects liquid on none of them.

When to use it

No Droplet to send liquid to the first free place; Has Droplet to act on the first place that holds some, for example to pull a droplet out of whichever reservoir is filled.

How to read it

Blank and locked until the Zone Target cell has a zone type.

Typical value

Has Droplet.

Check order Zone Target tooltip

The order in which a zone type's regions are tried; the first match wins.

What it is

The order the regions were made in. A merged region keeps the place of its oldest part; an edited region keeps its place. Layer order, row folding and hiding do not change it, and hidden regions are still checked.

When to use it

Draw parking slots in the order you want them filled.

How to read it

All regions of the type are checked in one detection request, at the start of the step. A region whose electrodes have no channel number cannot be sensed and is skipped for both criteria. The chosen region's electrodes are switched on with the step's own electrodes and routes for every phase of the step; the step itself is not changed.

Typical value

See the tooltip; ids, oldest first.

When the step fails Protocol error dialog

The Zone Target column stops the protocol rather than guess.

What it is

The step fails, the protocol stops, and a Protocol error dialog shows why, when:

  • no region of the zone type meets the criterion (no region of zone type '…' meets '…'. Checked in order: …);
  • the zone type no longer exists (… is not defined on the loaded device. Pick another zone type or clear the Zone Target cell.);
  • the zone type has no region with a channel number, for example none on this device (… has no region with a channel-mapped electrode to check.);
  • droplet detection fails, or no answer comes within the wait time.
When to use it

Plan for the "all slots full" case: it ends the run.

How to read it

Like any failed step, MicroDrop then offers the run summary.

Typical value

Wait time 12 s, in Protocol Settings ▸ Column Ack Wait Times (0 = don't wait). At 0 the step fails at once: the column needs the detection answer.

What is recorded run log and run report

Each resolved step logs which region it chose and why.

What it is

The log line reads like Step 3: zone target 'zone-1' (No Droplet) chose region zone-1-6 (checked in order: zone-1-4, zone-1-5, zone-1-6); actuating […]. The run report's data files get three values for the step: Zone Target, Zone Target Criterion and Zone Target Region (stored, not charted).

Preview mode Play button menu ▸ Preview Mode

A preview run skips the Zone Target column.

What it is

Detection needs the DropBot, so in preview the step runs with only its own electrodes and routes, and the log notes that the zone target was not resolved.

Where zones are kept

WhatKept inSaved when
Zone types: name and colourMicroDrop preferences, shared by all devicesAt once, on every change
RegionsThe device SVG's Zones layer, with each region's zone name and colourOnly on File ▸ Device ▸ Save / Save As…
Live copy for other pluginsShared app data (snapshot)At once, on every change

Loading another device clears the regions on screen and the zone undo history, then loads the new file's Zones layer. Zone types stay. A region in the file whose zone type does not exist here gets that type re-created from the name and colour stored in the file. If a zone type with that id already exists, the local name and colour are used.

Caveats

  • Save the device yourself. Zone edits do not mark the device as changed, so there is no Unsaved Device SVG Changes warning. Unsaved regions are lost when another device is loaded or MicroDrop is restarted.
  • Region numbers are not ids. The table counts 1, 2, 3; the tooltip, log and report say zone-1-4. Hover a row to match them.
  • Zone Target uses what is on screen now, saved or not, and checks hidden regions too.
  • Check order is the order the regions were made in. To change it, redraw the regions in the order you want (or merge into the oldest one); the layer arrows do not affect it.
  • A full zone ends the run. When no region meets the criterion the step fails and the protocol stops.
  • Moving a device file to another computer brings its regions and their zone names and colours, but a zone type that already exists there keeps that computer's name and colour.
  • Outlines are computed. On some chips they trace every electrode instead of one shape (see Outline).

Glossary

Zone type
A named, coloured label for a kind of place on the chip.
Region
A set of electrodes carrying one zone type.
Region id
A region's permanent name, such as zone-1-4; never reused.
Commit
Turning a dashed selection into a region.
Layer
A zone type's place in the drawing order; the first row is on top.
Check order
The order the Zone Target column tries a zone type's regions in: oldest first.
Actuate
Switch electrodes on, so they pull liquid.
Channel
The DropBot output an electrode is wired to; detection and switching work per channel.
Device / SVG
The drawing of a chip design's electrodes, loaded from an .svg file.
